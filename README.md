# HP Sneakers Store

HP Sneakers Store là hệ thống thương mại điện tử được phát triển trong khuôn khổ đồ án môn học. Hệ thống hỗ trợ bán giày trực tuyến, quản lý sản phẩm, quản lý tồn kho, xử lý đơn hàng và tích hợp thanh toán trực tuyến thông qua VNPay.

---

# Chức năng chính

## Khách hàng

- Đăng ký / Đăng nhập
- Xem danh sách sản phẩm
- Tìm kiếm sản phẩm
- Quản lý giỏ hàng
- Đặt hàng
- Thanh toán qua VNPay
- Theo dõi đơn hàng

## Quản trị viên

- Quản lý sản phẩm
- Quản lý tồn kho
- Quản lý đơn hàng
- Quản lý danh mục
- Dashboard quản trị
